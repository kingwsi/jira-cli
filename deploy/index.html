● ● ● [ 安装使用与排错引导 / Installation Guide ]
1. 下载与解压 解压下载包至任意目录：
tar -xzf jira-darwin-arm64.tar.gz
赋予权限：chmod +x jira
2. 启动工作台 终端执行：
./jira -open
自动打开 http://127.0.0.1:8899
3. 系统全局命令 可选移动至环境变量目录：
mkdir -p ~/.local/bin && mv jira ~/.local/bin/
💡 macOS 常见问题处理：
• 环境变量提示：一键安装默认放置在 ~/.local/bin，若提示 command not found: jira，可在 ~/.zshrc 中加入 export PATH="$HOME/.local/bin:$PATH" 并重开终端。
• 安全拦截：手动解压若提示“无法打开因为无法验证开发者”，在终端执行 xattr -d com.apple.quarantine jira 即可解除限制。
1. 下载与解压 解压 jira-windows-amd64.tar.gz 得到 jira.exe 绿色程序。
2. 直接双击启动 直接双击 jira.exe 启动前台服务，再访问 http://localhost:8899；自动打开浏览器请使用下方命令。
3. 终端命令行运行 PowerShell 中可执行：
.\jira.exe -open
💡 Windows 常见问题处理：
• SmartScreen 提示：首次双击若弹出 Windows Defender 保护提示，点击「更多信息」并选择「仍要运行」。
• 防火墙权限：首次运行弹出防火墙通信请求时，勾选专用网络并允许访问。
1. 本地解压 tar -xzf jira-linux-amd64.tar.gz
chmod +x jira && mkdir -p ~/.local/bin && mv jira ~/.local/bin/
2. 桌面直接运行 在图形界面终端执行：
jira -open
3. 服务器后台部署 nohup jira -H 0.0.0.0 -p 8899 > jira.log 2>&1 &
💡 Linux 服务化部署 (Systemd 守护进程示例)：
创建目录 ~/.config/systemd/user，在其中的 jira.service 写入：
[Unit]
Description=Jira Workbench Service
[Service]
ExecStart=%h/.local/bin/jira -H 0.0.0.0 -p 8899
Restart=always
[Install]
WantedBy=default.target
执行 systemctl --user daemon-reload && systemctl --user enable --now jira，随用户登录自动启动（不保证退出登录后继续运行）。
